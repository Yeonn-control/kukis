Punto de equilibrio — explicación práctica

Fórmula: Punto de equilibrio = Costos fijos / (Precio - Costo variable por unidad)

Ejemplo práctico: si tienes costos fijos (empaque + marketing) = $30.000 CLP, vendes galletas a $1.000 y el costo variable promedio por galleta es $417, entonces:

30.000 / (1.000 - 417) ≈ 30.000 / 583 ≈ 52 unidades. Es decir, necesitas vender ~52 galletas para cubrir costos fijos en ese escenario. Este cálculo te sirve para planificar cuántas vender en la feria.
